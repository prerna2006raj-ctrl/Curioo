# Curioo 🔍

An AI-powered app that explains how everyday things work — type any topic and get a simple explanation, a step-by-step breakdown, and a real-world analogy, generated by Google's Gemini AI.

## Features

- **AI explanations** — powered by the Gemini API, with a custom prompt format for consistent, structured answers
- **Two modes, two vibes** — "like I'm 5" and "like an engineer" don't just change the wording, they change the whole UI: a playful pink/rounded theme for kid mode, a sharp blueprint-style theme for engineer mode
- **Dark mode** — a themed light/dark toggle: graph-paper light mode, cyanotype-blueprint dark mode
- **Voice input & read-aloud** — ask a question by speaking, and have the answer read back to you (Web Speech API)
- **Related topics** — every answer suggests 3 follow-up topics to keep exploring
- **Quick quiz** — generates a one-question multiple-choice quiz on the topic you just learned, with a confetti celebration for correct answers
- **Favorites** — save explanations, view them on a dedicated page, and export them all as a `.txt` file
- **Search history & suggestions** — recent searches are saved and autocomplete as you type
- **Browse by category** — jump into a random topic from Science, Technology, Space, Nature, Human Body, or History
- **Topic of the day** — a new topic to explore every day
- **Stats tracker** — tracks how many topics you've explored, total and this week
- **Sign up / log in** — a simple demo auth flow stored in the browser (not secure — for practicing the UX pattern only)
- **Installable (PWA)** — add Curioo to your phone or desktop home screen like a native app

## Tech stack

React · Tailwind CSS v4 · Vite · Google Gemini API · Web Speech API · vite-plugin-pwa

## Setup

1. Clone the repo
2. `npm install`
3. Get a free API key from [Google AI Studio](https://aistudio.google.com/apikey)
4. Create a `.env` file in the project root:
   ```
   VITE_GEMINI_API_KEY=your_key_here
   ```
5. `npm run dev`

## What I'd improve with more time
