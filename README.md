   # Curioo 🔍

   An AI-powered app that explains how everyday things work — type any topic and get a simple explanation, step-by-step breakdown, and analogy, generated by Google's Gemini AI.

   ## Tech stack
   React, Tailwind CSS, Vite, Gemini API

   ## Setup
   1. Clone the repo
   2. `npm install`
   3. Add your own `VITE_GEMINI_API_KEY` in a `.env` file
   4. `npm run dev`
